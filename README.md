# Nutriponta - Apresentação Institucional 2026

Apresentação comercial e institucional interativa, responsiva e otimizada da Nutriponta Pet Food.

## 🚀 Tecnologias

- HTML5 Semântico & CSS3 (Mobile-First Architecture)
- JavaScript Vanilla ES6+ (High-Performance Slide Engine)
- Google Fonts (Plus Jakarta Sans)
- Vercel Ready (Security & Caching Headers)

## 📱 Recursos

- **Mobile-First & Touch Support**: Navegação por gestos de *swipe* e dock de botões otimizado para o polegar.
- **Acessibilidade WCAG AA**: Atalhos de teclado, suporte a leitor de tela e alvos de toque min 44x44px.
- **Catálogos Interativos**: Links diretos para catálogos digitais de produtos.
- **Suporte a Impressão/PDF**: Layout limpo e otimizado para exportação para PDF via `@media print`.
